# بسته کامل SEO و GEO آتبین‌یار

این بسته برای انتشار در ریشه مخزن GitHub Pages دامنه `atbinyar.ir` آماده شده است.

## محتویات

- `index.html`: صفحه اصلی با عنوان/توضیحات متادیتا، canonical، Open Graph، کارت اشتراک‌گذاری، Schema.org و لینک‌های واقعی و قابل خزیدن به راهنماها.
- `prime-numbers.html`: راهنمای عددهای اول و غربال اراتستن.
- `prime-factorization.html`: راهنمای تجزیه عدد به عوامل اول.
- `divisors.html`: راهنمای شمارنده‌ها و مقسوم‌علیه‌ها.
- `gcd-lcm.html`: راهنمای ب.م.م و ک.م.م.
- `number-analysis.html`: راهنمای تحلیل ویژگی‌های عدد.
- `about.html`: معرفی پروژه و تفکیک امکانات برنامه از وب‌سایت معرفی‌کننده.
- `404.html`: صفحه خطای سفارشی برای آدرس‌های پیدا نشده (عمداً در sitemap نیست و `noindex` دارد).
- `robots.txt`: اجازه خزیدن عمومی، اجازه `OAI-SearchBot` برای جست‌وجوی ChatGPT و عدم اجازه `GPTBot` برای استفاده آموزشی از خزنده جداگانه.
- `sitemap.xml`: فهرست همه URLهای حاضر در همین بسته.
- `llms.txt`: معرفی خلاصه و راهنمای ارجاع برای سیستم‌های هوش مصنوعی؛ این فایل استاندارد رسمی رتبه‌بندی گوگل نیست و هیچ نتیجه‌ای را تضمین نمی‌کند.
- `assets/seo-pages.css`: استایل مشترک راهنماها با ظاهر دفترچه‌ای و حالت شب.
- `assets/atbinyar-social.png`: تصویر 1200×630 برای پیش‌نمایش شبکه‌های اجتماعی.
- `CNAME`: دامنه سفارشی GitHub Pages.
- `.nojekyll`: غیرفعال‌کردن پردازش Jekyll در انتشار ایستا.

## انتشار امن

1. از مخزن فعلی نسخه پشتیبان بگیر.
2. فایل‌های داخل این بسته را در **ریشه مخزن منتشرشونده** کپی کن و فایل‌های دیگر موجود را که در این بسته نیستند (مانند `logo.png` یا تنظیمات پروژه) بی‌دلیل حذف نکن.
3. `index.html` را جایگزین نسخه قبلی کن و فایل‌های جدید را اضافه کن.
4. Commit و Push کن؛ سپس بررسی کن GitHub Pages از همان branch/folder انتشار می‌دهد.
5. این آدرس‌ها را پس از انتشار در مرورگر باز کن:
   - https://atbinyar.ir/robots.txt
   - https://atbinyar.ir/sitemap.xml
   - https://atbinyar.ir/llms.txt
   - https://atbinyar.ir/prime-numbers.html
6. در Google Search Console، از بخش Sitemaps مقدار `sitemap.xml` را ثبت/ارسال کن. سپس با URL Inspection صفحه اصلی و صفحات جدید را جداگانه بررسی و در صورت نیاز درخواست ایندکس بده.
7. برای بررسی Schema، URL منتشرشده را در Rich Results Test و Schema Markup Validator وارد کن؛ کد موجود در این بسته به‌صورت محلی از نظر JSON معتبر شده، اما نتیجه ابزارهای بیرونی بعد از انتشار باید بررسی شود.

## تصمیم خزنده‌های هوش مصنوعی

`OAI-SearchBot` مجاز است تا محتوا امکان بررسی برای ChatGPT Search را داشته باشد. `GPTBot` جداگانه مسدود شده است چون خزنده جست‌وجو و خزنده آموزش دو کاربرد مستقل دارند. اگر می‌خواهی محتوای عمومی سایت برای GPTBot نیز مجاز باشد، می‌توانی خط‌های `User-agent: GPTBot` و `Disallow: /` را با `Allow: /` عوض کنی. این تنظیم بر حضور تضمینی در پاسخ‌های هوش مصنوعی اثر قطعی ندارد.

## محدودیت‌های صادقانه

- این تغییرات ساختار و زیرساخت SEO/GEO را بهبود می‌دهد ولی رتبه اول، نمایش برای هر عبارت یا ورود قطعی به پاسخ‌های هوش مصنوعی قابل تضمین نیست.
- داده ساختاریافته بدون نظر یا امتیاز واقعی اضافه‌شده است؛ هیچ Review یا AggregateRating ساختگی در کد وجود ندارد.
- `sitemap.xml` فقط URLهای موجود در همین بسته را فهرست می‌کند؛ هنگام اضافه کردن صفحه جدید، آن را به sitemap و لینک‌های داخلی اضافه کن.
- صفحه‌های راهنما آموزشی‌اند و تظاهر نمی‌کنند که ابزار محاسباتی واقعی را داخل مرورگر اجرا می‌کنند.
- وضعیت زنده در زمان ساخت بسته قدیمی بود؛ بعد از انتشار باید crawl/index جدید را از Search Console بررسی کرد.
